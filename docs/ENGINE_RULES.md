# 基础执行引擎规则（第三阶段）

本文件规定本教学软件自己的简化行为，未声称复现 Rockwell 2080-LC50-24QVB 的真实扫描时序、指令或安全功能。不连接硬件。

1. 所有变量都是布尔量，初始为 FALSE。输入由虚拟开关设置，输出和内部标志由线圈写入。输入未指定时为 FALSE；不能通过输入开关写输出/内部变量。
2. 执行前检查整个程序。有结构错误、未知拓扑/指令/变量类型或重复标识时拒绝整次扫描，不执行部分网络。无触点网络作为提示，允许运行，其串联条件为 TRUE。多个线圈写同一变量作为错误。
3. 每次扫描先取得输入快照，然后按界面从上到下执行网络。每网络从左到右计算所有触点：常开条件等于变量值，常闭条件等于变量值的取反；串联是所有条件同时成立。
4. 每个网络末端线圈立即写入串联结果，包括 FALSE。后面的网络读取前面刚写入的输出/内部变量。读取本网络线圈或后面网络的目标时，读到的是尚未被本次扫描改写的上一次值。未被线圈写入的内部/输出变量保持原值，初始为 FALSE。
5. 每次扫描保存输入快照、每个触点读到的值/条件/串联通路和线圈前后值，供高亮与后续动态解释使用。不因前面条件为 FALSE 而省略后面触点的记录。
6. “运行”立即扫描一次，此后由浏览器按名义 200 ms 间隔扫描；后台标签页可能被限速，不保证真实时间。“单步扫描”只扫描一次。单步和运行都先检查结构。
7. “停止”取消连续扫描，保留输入、最后变量值、扫描次数和高亮；停止后的输入开关只改变下一次待采样输入。再次运行从保留值继续。停止状态不是硬件断电。
8. “复位”停止扫描，把输入、输出、内部变量和扫描次数清零，清除轨迹，不修改梯形图。运行中禁止修改程序；停止后修改程序会自动复位，避免旧结果与新图混用。
9. 切换学习模式保留运行状态；切换实验会停止并复位运行状态，保留各实验的程序。旧实验的计时回调不得改变新实验结果。刷新或关闭仍丢失网页草稿。

当前支持常开/常闭、串联、普通布尔线圈和多网络。并联、定时器、计数器与其它指令不执行。第三阶段提供变量调试，不实现实验装置动画、完整实验课程或“为什么这样运行？”动态分析。
