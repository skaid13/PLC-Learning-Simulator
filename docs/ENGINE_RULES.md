# 教学执行引擎规则（1.0.0）

这些规则定义本软件自己的教学行为，不复现 Rockwell 2080-LC50-24QVB 的真实扫描时序、指令、运动轴、电气或安全功能。

## 变量与结构

- 输入/输出为布尔量，内部变量可以是布尔或数值。布尔初值 FALSE；数值回到定义的初值，默认 0，范围 ±1,000,000。
- 输入只能由虚拟开关或自动传感器提供，不能作为末端写入目标。物理 I/O 由指导书目录固定，SIM 名称为教学名称。
- 每程序至少一个网络，每网络一个末端指令；每串联支路最多 4 触点，最多 8 条支路。主支路与附加支路是 OR，每支路内部是 AND。空支路是 TRUE，并给出提示。
- 执行前校验整个程序。未知指令、类型不符、未绑定、重复标识、无效参数、普通线圈重复写等错误阻止整次扫描，不执行部分网络。
- 一个变量只能有一个普通线圈或定时器来源；SET/RESET 可以有多个来源，MOV/ADD 可以有多个来源，CTU 可与计数复位共用完成变量。每个完成变量只能有一个 CTU。

## 一次扫描

1. 采样待输入快照。自动传感器开启时，位置/液位按扫描开始的装置状态生成；手动模式使用开关。传感器冻结保留上次采样值。
2. 按界面从上到下执行网络，从左到右计算支路中的所有触点，即使前面的条件为 FALSE 也记录后面的读值。
3. 常开在变量 TRUE 时成立，常闭在 FALSE 时成立。比较触点按 eq/ne/gt/ge/lt/le 与常数比较，使用数值变量；比较结果不再被常开/常闭符号反转。
4. 上升沿检测记录“原始条件”在前次扫描的状态；本次条件为 TRUE 且前次为 FALSE 时，只导通一次。串联中前面条件不成立时，也更新该触点自己的边沿记忆。
5. 合并支路结果并执行末端指令。写入立即生效，后面的网络读到新值；前面的网络读到前次扫描的保留值。顺序控制参考程序使用扫描开始的步骤快照，避免同一扫描连续跳步。
6. 每次扫描推进固定逻辑时间 **200 ms**，保留输入值、每个触点读值/判断/局部通路、支路 OR、指令前后值、实际写入标记、计时/计数。
7. 用最终输出推进一次装置模型，然后下次扫描再采样更新后的传感器。装置不自行执行参考程序的步骤。

## 末端指令

| 指令     | 规则                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| 普通线圈 | 每扫描写入通路结果，包含 FALSE                                                                                        |
| SET      | 通路 TRUE 写 TRUE；否则不写，保留旧值                                                                                 |
| RESET    | 通路 TRUE 写 FALSE；否则不写                                                                                          |
| TON      | 通路 TRUE 时累计每次扫描时间，达到预置时完成值 TRUE；通路 FALSE 立即清累计并写 FALSE                                  |
| TOF      | 通路 TRUE 立即输出 TRUE；下降后累计时间，达到预置才输出 FALSE；初始通路 FALSE 不产生延时输出                          |
| 周期脉冲 | 通路 TRUE 时累计，到预置时输出 TRUE 一个扫描周期并扣除一个周期；通路 FALSE 清累计。预置至少 400 ms                    |
| CTU      | 对网络通路的上升沿加一，不是对每次 TRUE 扫描加一。达到正整数预置时完成值 TRUE；计数最大 1,000,000，可绑定数值显示变量 |
| 计数复位 | 通路 TRUE 清计数、完成值及绑定显示变量；保留前次通路状态，持续高电平不被当作新计数沿                                  |
| MOV      | 通路 TRUE 写入常数或来源数值；FALSE 保留                                                                              |
| ADD      | 通路 TRUE 将常数或来源数值加到目标，负常数表示减法；FALSE 保留。MOV/ADD 结果限制 ±1,000,000                           |

计时器和计数器状态按完成变量隔离，触点边沿状态按元件 ID 隔离。修改程序、复位或切换实验清除这些状态。同一变量存在多个合法写入时，按网络顺序，**最后实际写入**决定最终值；未触发的 SET/RESET/MOV/ADD 不能冒充写入来源。

## 控制与时间

- 运行立即扫描一次，然后按名义 200 / 速度倍率 ms 触发。倍率 1/5/20 只改变墙上等待时间，每扫描仍推进 200 ms 逻辑时间。后台页限速会让仿真变慢，不保证真实时间。
- 单步扫描一次并保持停止。停止取消计时器并保留输入、值、装置和轨迹；停止不等于断电。输入变化等下次扫描才反映。
- 复位停止并清扫描/记忆/输入，恢复装置初始状态，解除故障注入；数值恢复定义初值，保留程序。
- 运行中锁定编辑、撤销/重做和导入/载入。修改程序自动复位。切换模式保留运行，切换实验停止并复位，保留各实验草稿。
- 旧程序计时回调通过程序引用检查被忽略；卸载/停止/倍率切换清理旧 interval。

## 装置与解释边界

装置变化由 `src/simulation/plant.ts` 计算：步进依有效输出边沿和使能；机械手/电梯依方向输出积分；水位依泵/阀输出变化；灯、数码管、工位直接读输出。相反运动输出会被教学模型互锁并提示，执行器卡滞冻结物理变化但不篡改程序输出。各实验速率、频率、歧义处理见界面和 README 表格，均为教学设定。

执行解释读当前最后扫描的轨迹，而不是读取后来更改的输入去倒推。可选择输出或内部变量，列出按顺序执行的所有写入网络，标出最后实际写入，并定位元件。未扫描时明确无法说明原因；未被网络写入时说明初值/保留值。解释程序行为不等于确认控制逻辑满足全部实验要求，也不意味着物理装置一定动作。

草稿、保存/恢复和 JSON 只包含程序结构，不持久化运行值和轨迹。导入使用字段白名单与边界检查；未绑定的草稿可导入，结构错误在运行前拦截。
