# PLC学习实验室 2.0.0

2.0将已存档1.3.0（远程基线 `d853626`）之后的教学重构、界面优化与桌面封装合并为一个版本。原实验、扫描引擎、指导书和学生程序格式继续保留，重点解决“第一次进入不知道从哪里开始”和“学习结束不清楚后台是否还在运行”。内部1.4/1.4.1开发检查点保留在Git历史中，不改写旧版本。

## 新手学习主线

- 首页提供唯一明确的第一课入口和真实学习阶段进度，课程、知识与完整工作台入口集中呈现。
- 第一课“按钮亮灯”按认识对象、观察示例、跟随搭建、补全程序、独立搭建、变化任务六阶段展开，逐步撤去帮助。
- 先说明按钮、触点、线圈与灯的关系，再操作真实可运行示例；输入TRUE/FALSE均需预测并扫描，验证常开和常闭的不同结果。
- 搭建阶段根据实际工具选择、程序结构、变量绑定和扫描结果判定完成；错误预测、错误变量和缺失元件提供具体反馈与分层帮助。
- 修改程序会清除过期验证证据，不能用旧运行结果替新程序过关。阶段草稿独立保存，退出后可以继续，重建前提供备份和确认。
- 六阶段新主线目前仅覆盖第一课。十课基础课堂、三个入门项目和11个正式实验及原有分层课程/引导保留，不宣称全部实验已完成同样重构，也不以测试通过代替真实零基础试学。

## 元件知识与信息组织

- 集中知识工具箱，按信号、条件、时间/次数与操作组织主题，解释用途、选择理由、相近对象区别、最小例子、易错点和验证方法。
- 包含输入/输出/内部变量、常开/常闭、线圈、串并联、SET/RESET、定时、计数、边沿以及运行/停止/复位等。
- 明确区分软件触点逻辑判断与真实按钮接线方式，明确停止、复位运行和重建程序的区别。
- 当前任务突出一个主要动作，说明按需展开；保留原完整工作台自由编辑、参考程序、撤销重做及JSON工具。

## 界面与运行反馈

- 统一为蓝白配色、白色学习页、本地中文系统字体与SVG元件符号，不依赖网络字体或装饰素材。
- 首页、六阶段导航、知识库与编辑器采用统一的按钮、焦点、选中和禁用状态；窄屏知识主题改为选择控件，避免信息挤在一起。
- 第一课使用真实目标高亮与任务区说明，避免浮动说明遮住扫描结果；预测、输入、程序判断、输出和灯状态相互对应。
- 结构示意图明确标注为示意，实际运行继续由公共扫描/装置引擎驱动，无预设动画冒充程序执行。

## 独立桌面应用

- Electron封装独立窗口，应用自带运行环境和离线资源，不需要终端、系统Node.js、浏览器标签或本机HTTP服务。
- 关闭最后窗口或Command+Q退出整个应用；重复打开聚焦同一实例。最小化仍保留运行窗口，区别于退出。
- 固定应用数据目录与应用身份，升级替换.app时保留数据。应用内采用受限资源协议、隔离渲染环境与路径校验，阻止外部导航和资源请求。
- 提供原生文件保存/选择、编辑菜单、缩放、全屏和“学习数据”入口。没有云同步、自动更新、账户或付费API。

## 学习数据与升级

- 首页和原生菜单可备份、恢复或迁移全部学习记录，包含程序及教学进度；备份只包含本软件已知存储键。
- 导入先校验并预览，要求保留当前备份及明确确认；写入失败回滚，同名项替换，其它记录保留。
- 浏览器与桌面存储相互隔离。原网页用户应先导出学习数据，再在桌面应用主动导入；不会偷偷读取或清除浏览器资料。
- 单程序JSON仍为 `schemaVersion: 1`，不迁移硬件工程。旧学生程序与原11实验保留；第一课使用独立草稿，不自动覆盖已有工作台程序。
- Mac应用数据在 `~/Library/Application Support/PLC-Learning-Simulator/`。升级前建议通过界面另存学习备份；替换应用时保留此目录。个人学习文件不上传到公共仓库，也不打入应用附件。

## 旧网页版退役与开发方式

- 已确认的旧网页服务停止；旧网页构建、Mac/Windows网页启动入口、静态服务器和重复打包/临时文件移入系统垃圾桶。未永久删除、清空垃圾桶或卸载共享开发环境。
- 保留共用React源码、锁文件、指导书、Git历史、必要依赖、学习数据和导出备份。恢复路径见 [清理记录](CLEANUP_REPORT.md)。
- `npm start` 构建后打开开发桌面窗口；`npm run build` 生成桌面资源。`npm run dev` 仅供开发者调试，不作为日常网页交付。
- macOS arm64、macOS x64和Windows x64分别提供 `package:mac`、`package:mac:intel`、`package:win`。Windows使用 `npm.cmd`；依赖应在目标系统重新安装。

## 下载与平台范围

Release提供 `PLC-Learning-Simulator-2.0.0-mac-arm64.zip`，解压后将 `PLC学习实验室.app` 放到个人“应用程序”目录再打开；不需要Node.js或额外服务器。已有用户替换旧.app前先退出，保留App Support数据目录。校验文件为 `SHA256SUMS.txt`。

此Mac包未签名、未公证；不同电脑上的首次打开可能受到系统安全检查，不能等同于完成对外分发验收。本轮不提供Windows/Intel Mac二进制文件，这两个平台的配置与源码保留，尚未完成实机测试。应用不连接实体PLC，不能将教学仿真描述为真实PLC完整工程能力或硬件下载工具。
