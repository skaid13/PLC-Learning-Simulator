## 范围与布局决定

- 沿用Taste已有Framed sheet方向（先前seed141）、用户确认的蓝白配色与本地字体；按UI UX Pro Max的动态视口单位和内容溢出规则调整，不增加素材/依赖。
- 界面回答“本阶段该做什么、程序怎样影响灯”：左侧任务自然高度，右侧线路/输入/真实执行为主区域，主区域随窗口高度使用剩余空间。
- 白色学习页延伸至窗口底部，阶段切换栏落在页底，下一阶段位于右侧；不使用覆盖内容的fixed导航或强制裁切。
- 保存状态并入标题说明同一行，减少重复的整行提示；短窗口压缩留白，高窗口放大线路符号和输入/灯的观察区。
- 认识对象采用大符号与用途说明并排；四项阅读后说明区收紧，为理解题腾出空间，去掉题目末尾重复的已读计数。
- 所有现有真实扫描、错误反馈、下方属性、图上变量、草稿与schemaVersion1保持。窄屏自然纵向阅读，展开帮助可增加页高，不隐藏内容。
