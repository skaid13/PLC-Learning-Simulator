## 学习入口

原六步介绍和单道输入识别题已替换为四个可展开的概念，解释 PLC、输入输出/变量、梯形图和扫描。三个独立小项目位于入门卡片与实验选择框：

| 项目     | 新知识                      | 操作验收                                                             |
| -------- | --------------------------- | -------------------------------------------------------------------- |
| 按钮亮灯 | 常开、普通线圈、输入采样    | 接通/断开后分别用新的单步验证亮/灭                                   |
| 停止条件 | 常闭、串联、停止优先        | 先完成亮灯，再加常闭停止；验证停止及解除                             |
| 延时亮灯 | TON、ms、持续计时、断开清零 | 先立即亮灯，再改 TON 2000 ms；观察提前断开清零、重新累计、完成和熄灭 |

每个项目有任务、搭建思路、先预测后对照、独立变式和实际输出驱动的灯。新项目采用独立 experimentId，草稿/引导进度各自保存。JSON 仍为 schemaVersion 1；旧实验格式保留，新项目需使用 1.2.0 或更新版本载入。

## 操作引导

默认自动前进：真实操作产生新状态且当前验证通过时推进。错误绑定不推进，扫描验证不能复用旧扫描。编辑器记录实际点击次数，重复选择同一个元件也能被识别；挂载通知不会冒充用户动作。刷新和恢复保留位置，不自动跳过已存在的正确状态。

取消“完成操作后自动前进”可手动验证；回顾上一步自动切成手动，避免立刻跳回。模式偏好单独保存在当前浏览器。定位、检查、提示、重试、跳过和退出均保留；“检查本步”可明确报错，自动模式检查成功可主动推进。

## 元件解析与界面

工具与选中元件旁附可展开解析，包括指令行为、用法例子和易错点。覆盖常开/常闭、比较、普通线圈、SET/RESET、TON/TOF、周期脉冲、CTU/复位计数、MOV/ADD；上升沿启用时附解释。

入门卡片、任务、预测、观察与变式分层显示。浮动提示收窄移到右下，窄屏收起重复正文；目标高亮与手动定位保留。修正要求弹窗中“尚未实现教学和仿真”的过时说明，独立项目明确标为额外教学练习。

## 接续与更新

GitHub 当前仍为原 main：没有当前账号的推送凭据，写权限预检查未通过。交付包提供完整源码、正式构建、更新补丁和接续说明。推荐把更新补丁交给用户电脑上的 Codex：先检查当前 Git 差异、保存本地修改，再检查补丁能否应用；出现冲突时按文件合并，不覆盖用户的新改动。应用后运行上述检查并重新构建正式版。
