# 2.0.2：教学布局、编辑状态与代码整理

基于2.0.1小步迭代，包含本机试用的布局修订与本次代码优化。保留全部现有实验、课程、macOS/Windows源码和离线运行方式；学生程序继续使用schemaVersion 1，无迁移要求。

## 教学布局

- 学习页随窗口高度展开，减少全屏下方的剩余空白；主观察区使用更多空间显示线路、输入和灯。
- 保存状态与标题说明合行，当前任务保留在左侧，阶段操作位于页底，“下一阶段”在右侧。
- 认识对象使用大符号与用途说明并排；读完四项出现习题时，卡片和说明区收紧，为答题留出空间，去掉重复已读计数。
- 桌面短窗口保留紧凑样式，窄屏自然纵向阅读；展开详细说明仍可增加页高，不通过裁切隐藏内容。

## 编辑行为与代码优化

- 重复选择相同变量、保存相同名称、越界移动、更新/删除不存在对象等不再生成“新程序”。避免无实际变化时误复位扫描、清除教学证据、写入草稿或增加空撤销记录。
- 真实修改继续生成不可变的新程序，保留未改动的网络、分支和变量引用；真实改绑仍取消完成状态，撤销/重做继续有效。
- 修复变量浮层在pointerdown阶段关闭引起的第一次撤销点击落空；改为click捕获关闭，单次点击即可撤销，切换元件仍能打开对应浮层。
- React运行时独立打包：应用约286.50KB、React约218.75KB、打包运行时约0.58KB，单包大于500KB的警告消失。总JS约505.83KB，基本不变，不将拆包描述为总下载量或启动耗时降低。没有调高警告阈值、引入CDN或增加依赖。
- 合并重复教学样式声明，保留短窗口/窄屏覆盖，构建CSS约79.45→79.20KB。

## 冗余文件与数据保留

- 导入图及全局引用核对后，移走无人使用的旧`src/data/lesson.ts`常量；只在历史目录清单中出现，不是当前课程入口。旧源码可从Git历史或垃圾桶恢复。
- 旧应用、旧安装包及确认的重复构建/临时清单移动到系统垃圾桶，移动前后校验，不永久删除或清空垃圾桶。源码、原指导书、锁文件、构建配置、依赖、Git历史及用户备份保留。
- 应用身份和`~/Library/Application Support/PLC-Learning-Simulator/`数据位置不变，升级前保留本地完整备份。个人学习数据不上传GitHub。
