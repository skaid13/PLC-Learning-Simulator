## 阶段与验收

1. 对象阅读：默认展示的第一项计为已读，四项看完后才出现理解题，错误答案不能进入下一阶段。检查既有六阶段和存储失败路径。
2. 扫描与重复流程：保持默认FALSE，明确先预测并扫描断开，再接通验证；检查补全/独立/常闭变式的同类引导。第三阶段只要求正确搭建和检查结构，观察示例与后续独立验证保留真实执行要求。
3. 布局：观察线路、输入、预测、扫描和结果同屏，压缩无效纵向空间，主操作/下一阶段不被遮挡；在桌面、全屏与窄屏实测。长篇拓展内容按需展开，不强行缩小字号或隐藏错误。
4. 梯形图变量编辑：元件旁可直接选择变量、修改名称、创建并复用内部变量；保留下方编辑，复用同一程序数据和撤销重做。保持地址/ID不变、按类型过滤、运行锁定、重开/JSON恢复可用。最后全回归、桌面打包与本机交付。

每阶段进行相关测试、类型/构建和实际页面验证，记录通过/失败/未测，更新进度/日志并保存独立Git检查点。存在主流程错误先修复，不弱化有效断言。

## 界面约定

沿用已验收的蓝白色、本地字体及Framed sheet方向（先前seed141），不重新设计品牌。教学页的核心问题是“当前唯一动作是什么、结果在哪里”；编辑器的问题是“这个元件读写哪个变量”。SVG线路与真实扫描是本产品的主要对象，不引入装饰图表或联网资源。

应用UI UX Pro Max的标签、就近反馈、键盘可达与渐进呈现原则，并按Taste应用界面规则检查布局。技能对progressive disclosure两次查询都偏到标题换行，未采用为已验证依据，使用既有教学结构与通用交互判断。浏览器实测使用提供的页面工具，不使用技能的CDP自动化检查器；未执行的检查不记通过。
