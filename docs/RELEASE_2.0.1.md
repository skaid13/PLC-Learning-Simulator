# 2.0.1：第一课流程与梯形图变量编辑修订

本次基于已发布的2.0.0迭代，按用户试学截图分四阶段修正。保留原实验、程序结构、教学草稿、桌面启动与离线执行方式。无需重建学习数据。

## 第一课：读完再答题

- 默认展开的第一张对象卡计入已读，初次进入显示1/4。
- 其余三张卡均阅读后才出现理解题；重复点击不会增加计数。
- 错误答案给出解释并阻止继续，正确理解后进入观察示例。

## 扫描顺序与学习节奏

- 初始输入为FALSE时，明确提示“保持断开，先做一次扫描”，无需先切换输入。
- 先预测再真实扫描，断开验证通过后提示接通验证；任务根据尚未完成的状态变化。
- 补全、独立、常闭变化任务使用相同机制，错误预测和初始化输出不计为扫描证据。
- 第三阶段“跟随搭建”仅要求正确搭建并检查结构，不重复第二阶段的两态观察。修改成错误结构会撤销放行状态，后续独立阶段仍需真实执行验证。

## 观察区域布局

- 将示例线路与输入、灯状态放在同一扫描区域，减少纵向分散和重复留白。
- 桌面帮助入口与定位按钮并排；切换阶段回到页首，目标已经可见时不再强制滚动居中。
- 原生Mac全屏实测核心线路、预测、扫描结果及下一阶段按钮同屏。浏览器1666×1000、1440×900、1280×800检查通过；390窄屏无横向溢出，保留正常纵向阅读。

## 直接在梯形图旁编辑变量

- 点击已有元件或放置元件后，就近打开变量编辑框；原下方属性编辑区继续保留。
- 图上可选择变量、修改名称、创建并绑定内部变量，显示本程序内可再次调用的自定义变量。
- 第二个元件可复用同一个变量；改名同步已有引用，物理地址、变量ID和端子保持不变。
- 创建与绑定为一次可撤销编辑，支持重做、刷新恢复及schemaVersion 1 JSON往返。
- 校验空名称、重名、指令类型与变量类型、输入端子写入限制；错误就近提示。
- 编辑框随窗口与滚动定位，支持关闭、外部点击、Escape；运行时锁定编辑。
