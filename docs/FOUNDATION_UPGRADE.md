## 教学判断

1.2.0解决了操作负担和入门实践入口，但这些不能证明纯小白已经具备独立完成所有实验的概念基础。本轮增补文字课堂，目标是让学习者能解释条件、预测扫描结果、理解保持/时间/顺序，再去实践。

没有真实零基础学习者的试学数据，不能保证每个人独立学成11个实验。已读、看过答案、通过软件测试也不能替代学习验证。独立变式应能做到：遮住参考后说明任务和I/O，自己搭建，预测结果，用实际扫描验证，并解释停止和异常情况。

## 十课内容与学习路线

| 顺序 | 内容             | 学习任务                                 |
| ---- | ---------------- | ---------------------------------------- |
| 1    | PLC的作用        | 分清输入、程序判断、输出                 |
| 2    | 变量与TRUE/FALSE | 明确信息方向、类型和有效状态             |
| 3    | 扫描             | 区分待采样、最后结果、运行、停止和复位   |
| 4    | 触点与普通线圈   | 理解读条件和写结果，完成按钮亮灯         |
| 5    | 串并联与停止     | 将并且/或者/没有翻译为条件，做停止项目   |
| 6    | 保持             | 对比普通线圈与SET/RESET，说明停止优先    |
| 7    | 时间             | 区分TON/TOF/脉冲，做延时项目与提前断开   |
| 8    | 上升沿与计数     | 区分按住和新按下，避免每扫描重复ADD      |
| 9    | 阶段与顺序       | 先列阶段、转移、输出，解释互锁与扫描快照 |
| 10   | 设计与调试       | 从要求逐步搭建，测试正常/停止/重启/边界  |

每课包含目标、两段主题讲解、逐步推理例子、两道可展开的自查问题、易错点和对应项目入口。自查为自由解释，不自动判分。理论阅读与项目操作可来回切换。

## 入口与数据

工作台上方“文字基础课堂”随时可打开；入门地图也有突出入口。独立宽阅读窗口提供十课目录、上一课/下一课、已读记录。桌面目录与正文分列，窄屏堆叠；正文采用较大字号。

阅读位置和已读记录使用独立键 `plc-learning:foundation:v1`，不写入程序草稿或操作引导。使用稳定课题ID，损坏记录退回第一课；保存失败允许继续学习并显示反馈。跳转项目只切换当前工作区，保留已存在的草稿；重新打开课堂恢复阅读位置。
