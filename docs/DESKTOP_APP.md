# 1.4.1 桌面应用

## 阶段0：方案与现状（2026-10-21）

基线ba6e98a、工作区干净，新分支codex/desktop-1.4.1。复用React课程、编辑器和扫描逻辑，用Electron封装Mac/Windows。桌面版直接读取包内静态文件，不启动Node HTTP服务、不占4173、不打开终端；关闭最后窗口与Command+Q均退出整个应用，重复启动聚焦同一窗口。版本保持1.4.1，不上传/发布。

阶段1：安全桌面入口、跨平台打包配置、独立持久数据、全部学习数据的显式迁移/备份工具。备份仅包含本项目已知存储键，原浏览器数据不能自动出现在桌面应用中，也不得偷偷读取或清理浏览器资料。导入必须预览、明确确认并保留当前备份。

阶段2：macOS实际打包、启动、编辑/扫描、数据保存与恢复、原生JSON选择/下载、重复启动和关闭/退出进程检查。Windows配置与构建流程保留，不能将Mac测试当作Windows实机验收。

阶段3：安装到用户应用目录、桌面应用入口替换、停止已核实的本项目旧服务、旧快捷方式入垃圾桶、更新文档与检查点。源码、原指导书、锁文件、浏览器草稿、原启动脚本与Git历史保留。

参考：Electron官方protocol/security/app文档、electron-builder官方mac与多平台打包文档。没有开发者签名证书，不声称完成签名、公证或对外分发验收。
