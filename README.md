# PLC 实验教学与仿真系统

面向 PLC 零基础学生的本地学习软件。以《PLC实验箱实验指导书0827.docx》及其中的罗克韦尔 **2080-LC50-24QVB** 为参考，按阶段开发。当前版本 **0.2.0，第二阶段**：保留主界面、实验目录和基础入门教学，增加基础 SVG 梯形图编辑器。执行引擎尚未开放。

## 当前可以做什么

- 使用简体中文三栏工作台：教学指导、梯形图编辑器、实验仿真占位。
- 选择指导书中的 11 个实验，阅读实验目标、控制要求、I/O 摘要和原文疑点。
- 放置常开触点、常闭触点和输出线圈，选择变量、修改类型、移动和删除元件。
- 添加、命名、上下移动和删除网络；每个网络支持最多四个串联触点和一个末端线圈。
- 检查缺少线圈、未绑定变量等结构问题，点击提示定位到对应网络或元件。
- 在教学模式与自由模式间切换；切换时保留当前程序、入门学习位置和答题状态。不同实验有独立的内存工作区。
- 按六个步骤回顾入门课，学习 PLC、输入和输出的概念。
- 回答一道预设选择题，获得正确反馈或具体的错误原因，并查看参考答案。
- 点击“为什么这样运行？”查看“动态逻辑解释功能将在后续阶段开放。”
- 桌面采用三栏；较窄屏幕改为两栏或单栏并允许页面滚动。

这里的六步是全部实验共用的入门教学，**不是 11 个实验的完整课程**。编程步骤介绍当前基础编辑操作；运行步骤仍为后续任务说明。

## 初次绘制梯形图

1. 选择“常开触点”工具，点击网络中第一个“＋”空位。
2. 在下方“元件属性”的“元件变量”中选择输入变量，例如 LED 实验的 `SIM_IN_00 · 启动`。新元件不会自动绑定变量。
3. 需要更多条件时，选择触点工具，依次点击下一个可用空位。触点按从左到右顺序串联，连接线自动生成。添加按钮位于导线下方，空位上的导线表示直接连接。
4. 选择“输出线圈”，点击最右侧线圈空位，选择输出或内部变量，例如 `SIM_OUT_00 · A`。窄屏可在梯形图内向右滚动。
5. 点击已放置元件可重新选中；在属性区改变量、改触点类型、左右移动触点或删除元件。点击网络名称可编辑说明。
6. 点击“检查结构”，按提示补齐变量和线圈；点击诊断可定位。检查通过只说明基础结构可用，**不能判定实验逻辑正确**。
7. 使用“＋ 添加网络”组织更多网络。删除整个网络前会弹出确认；至少保留一个网络。当前没有撤销功能。

上面的输入与输出只是编辑操作示例，不是 LED 实验的完整答案。串联条件的计算、输入操作和设备输出留到后续阶段。

`SIM_*` 是本软件自定义的布尔教学变量。输入/输出变量与各实验指导书端子对应，另提供 `SIM_M_00`～`SIM_M_03` 四个内部标志。线圈不能写输入。四触点限制是本编辑器当前的教学范围，不是 PLC 硬件限制。`I-xx` / `O-xx` 只表示指导书端子，不能当作官方编程地址。

## 技术栈与环境

React、TypeScript、Vite、普通 CSS、SVG。无后端、数据库、登录、AI API 或外部字体/CDN。逻辑执行引擎尚未开发。运行时只读取本机资源，不需要真实 PLC 或官方编程软件。

需要 Node.js 和 npm，以及支持原生 `dialog` 的现代浏览器（例如当前的 Safari、Edge 或 Chrome）。建议使用 Node.js 24；本机验证环境为 macOS / Node.js 24.21.0 / npm 11.19.0。项目最低声明版本为 22.12.0。可从 [Node.js 官方网站](https://nodejs.org/) 下载对应系统安装包；Apple M4 选择 macOS ARM64 版本。Vite 安装基础参考 [官方入门文档](https://vite.dev/guide/)。

首次下载依赖需要联网，安装后本地开发及正式版本使用均可离线。依赖精确版本记录在 `package.json` 和 `package-lock.json`，不要在 Mac 和 Windows 之间复制 `node_modules`。

## Apple M4 Mac 如何启动

1. 安装 Node.js，重新打开“终端”。运行 `node -v`、`npm -v`，确认能显示版本。
2. 在终端进入本项目文件夹。可以输入 `cd `（末尾留一个空格），把 Finder 中的项目文件夹拖进终端，再按回车。
3. 首次运行：

   ```sh
   npm ci
   npm run dev
   ```

4. 保持终端打开，在浏览器访问终端打印的网址，通常是 **http://127.0.0.1:5173/**。如果端口占用，Vite 可能选择其它端口，以实际输出为准。
5. 停止服务：在终端按 **Control+C**。

本机依赖已经安装，日常再次启动只需 `npm run dev`。

## Windows 如何运行

1. 安装 Windows 版 Node.js，重新打开 PowerShell。
2. 在项目文件夹空白处右键选择“在终端中打开”（或用 `cd` 进入项目文件夹）。
3. 执行相同命令：

   ```powershell
   npm ci
   npm run dev
   ```

4. 浏览器打开终端显示的本机网址。终端需保持运行；结束时按 **Ctrl+C**。

同一份源代码和 npm 脚本适用于两个系统。尚未在 Windows 实机验证，不能视为已经完成 Windows 验收。

如果 PowerShell 提示 `npm.ps1` 无法运行，可使用 `npm.cmd ci`、`npm.cmd run dev`，无需更改系统执行策略。

## 构建与正式版本本地运行

```sh
npm run build
npm start
```

构建前先执行 TypeScript 检查，成功后输出 `dist`。`npm start` 使用 Node 标准库启动本地静态服务器，打开 **http://127.0.0.1:4173/**。服务器只监听本机地址；不公开发布。也可用 `npm run preview` 检查构建效果。

**不要直接双击 `dist/index.html`。** 构建使用浏览器模块，应通过本地服务器访问。`npm start` 不需要联网、不需要 Vite 或 `node_modules`；只需要已安装的 Node.js、`dist`、`scripts/serve.mjs` 和项目根目录的 `package.json`。必须保留它们的相对目录关系。

4173 端口占用时可使用其它端口：

- macOS 终端：`PORT=4174 npm start`
- Windows PowerShell：先运行 `$env:PORT=4174`，再运行 `npm start`

网页程序、学习位置和答案目前只保存在内存中。切换模式或实验会保留程序；**刷新页面、关闭网页会丢失**。尚无自动保存、手动保存或导入导出。Git 保存的是开发代码，不会保存网页中绘制的学生程序。

## 跨电脑迁移

**继续开发：** 复制项目文件夹，保留源码、`docs`、`scripts`、`package.json`、`package-lock.json` 和配置文件。排除 `node_modules`、`dist`、缓存。在目标电脑安装 Node.js 后运行 `npm ci`，再运行 `npm run dev`。首次安装依赖需联网。

**只使用正式版本且目标电脑离线：** 在已有环境运行 `npm run build`，复制 `dist`、整个 `scripts` 目录和 `package.json` 到另一台电脑的同一项目文件夹中。预先安装 Node.js 后，直接运行 `node scripts/serve.mjs` 或 `npm start`。无需下载项目依赖。若要核对指导书，可另带 `docs`。

将来的学生程序 JSON 导入/导出尚未实现；未来 JSON 也仅用于本教学软件，不是罗克韦尔真实工程文件。

## 如何检查当前版本

1. 默认进入教学模式：点击“下一步”，查看输入/输出解释，再用“上一步”回顾；也可直接点选步骤。
2. 点“理解检查”，先选择“指示灯”并检查，确认出现错误原因；改选“按钮”并检查，确认正确反馈；点“查看参考答案”。
3. 按上面的“初次绘制梯形图”完成一个基础网络，尝试改成常闭触点、移动或删除触点、添加并命名第二个网络。
4. 检查一个未完成网络：应出现缺少线圈/变量的诊断；点击提示定位，补齐后检查结果应即时更新。
5. 切到自由模式，确认显示自主练习说明，绘制的程序保留。切换另一个实验得到独立空白程序；切回原实验时原程序仍在。再切回教学模式，原来的步骤和答案也应保留。
6. 在两种模式下分别点击“为什么这样运行？”，只显示指定的未开放提示。可用关闭按钮、我知道了、Escape 或弹窗外部关闭。
7. 依次切换 11 个实验，确认右侧名称、输入输出数量、摘要和编辑器变量都跟随变化。
8. 运行、停止、复位按钮不可操作，画面不播放实验动画。
9. 缩窄浏览器，确认面板能够重排；梯形图内部可以横向滚动到线圈，页面整体不横向溢出。用 Tab 聚焦元件或空位后，Enter/空格应能选择或放置。

自动检查：

```sh
npm test
npm run build
```

当前 5 个测试文件、20 项测试通过。覆盖目录与关键 I/O 映射、教学功能回归、独立工作区、不可变编辑操作、结构检查、变量约束、完整编辑流程、排序删除和诊断定位。测试使用 Vitest、Testing Library 和 jsdom；SVG 连线、键盘、原生弹窗和响应式布局另用实际浏览器检查。具体结果见 `DEVELOPMENT_LOG.md`。

## 指导书目录与技术边界

实验顺序为 LED数码显示控制、步进电机实验、机械手实验、交通灯实验、三层电梯模拟实验、水塔水位控制的模拟控制、天塔之光的模拟实验、液体混合装置控制的模拟、装配流水线实验、自动售货机实验、自动配料/四节传送带的模拟实验。

原文目标与要求见 [提取记录](docs/MANUAL_EXTRACTION.md)。I-00 / O-00 等只作为指导书端子标记。真实罗克韦尔变量、指令语义和硬件能力尚未通过官方资料核实。本项目未采用西门子地址规则。原文点数、停止信号和时序等疑点保留并标注，不作为已验证事实。
